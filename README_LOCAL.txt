====================================================
   Zajel Express Admin - Local Setup Guide
====================================================

To run this application on your computer with ONE CLICK:

1. INSTALL NODE.JS (If you haven't already):
   - Go to https://nodejs.org/
   - Download and install the "LTS" version (Recommended for most users).

2. CONFIGURE YOUR DATABASE:
   - Open the file named ".env" with Notepad.
   - Fill in your Supabase credentials:
     VITE_SUPABASE_URL=your_url_here
     VITE_SUPABASE_ANON_KEY=your_anon_key_here
     SUPABASE_SERVICE_ROLE_KEY=your_service_role_key_here

3. START THE APP:
   - Double-click the file: "Zajel_Express_Start.bat"
   - The first time, it will download necessary files (this takes a minute).
   - Your browser will open automatically to the dashboard.

----------------------------------------------------
SUPPORTED SYSTEMS:
- Windows 7, 8, 10, 11 (32-bit and 64-bit)
----------------------------------------------------
NOTE: Keep the black window (Terminal) open while 
using the app. To close the app, just close that window.
